# 📘 Learning Source: Create GUI Applications with Python & Qt6 (PySide6)

This project follows along with the book:

**Create GUI Applications with Python & Qt6 — Sixth Edition**
*The hands‑on guide to making apps with Python*
**Author:** Martin Fitzpatrick
**Edition:** PySide6 / Qt6

All example code in this repository is written by **Jose “Joe” Ruiz** while studying the book chapter‑by‑chapter.

Some examples have been updated to reflect **modern PySide6 best practices**, including:

- Using explicit imports instead of wildcard imports
- Keeping widgets and enums inside their proper Qt namespaces
- Using Qt6‑style enums (e.g., `QLineEdit.Password`)
- Writing clean, class‑based GUI code with no globals
- Organizing each chapter’s work into clear, consistent folders

These updates ensure the code remains clear, explicit, and compatible with current PySide6 and Qt6 versions.
